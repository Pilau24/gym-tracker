# Gym Tracker

Gym Tracker is a web application for recording exercise, planning and tracking
diet goals, and sharing progress with a social community. It is being built
with account management and passkey-based authentication as a foundation for
future workout, nutrition, and social features.

## Tools and technologies

- Next.js 16 with the App Router, React 19, and TypeScript
- Tailwind CSS, Base UI, shadcn, and Lucide icons for the interface
- Prisma with SQLite for local data storage
- SimpleWebAuthn for passwordless passkey registration and sign-in
- pnpm, ESLint, and the TypeScript compiler for development and validation
